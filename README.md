# Jatin Dilip — portfolio

Live at https://jatindilip.vercel.app

Built with React, TypeScript and Vite.

## Run it locally

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

## Where to change things

- **All text** (projects, experience, skills, achievements, demo login) lives in `src/content.ts`.
- **Project screenshots** are in `public/projects/`. To update one, replace the `.webp` file with a new screenshot of the same name (about 1240 × 590 px works best).
- **Profile photo** is `public/profile.webp`.
- **CV** is `public/Resume.pdf`. Every "Download CV" button points to it.
- **Colours and fonts** are the variables at the top of `src/index.css`.
- **Sections** are in `src/components/site/`.
